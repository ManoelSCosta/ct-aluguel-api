# CT-ALUGUEL-API
Esta api permite que o cadastro de casas, inquilinose e contratos e também permite a geração de alguéis e registro de pagamento dos mesmos.

## Tecnologias Utilizadas
- Java 17
- Spring Boot 3.2.4
- PostgreSQL
- Spring Boot DevTools
- Spring MockMvc
- Spring Data JPA
- Spring Boot Data Bom
- Maven

## Pré-requisitos
- Instalar JDK versão 17
- Instalar Postgresql 15
